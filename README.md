# پروژه Rules

یک وب اپلیکیشن ساده برای مرور قوانین اصلی ایران و برگزاری آزمون بر اساس مواد قانونی. این پروژه با HTML, CSS و JavaScript خالص ساخته شده و برای اجرا روی GitHub Pages طراحی شده است.

**نام پروژه:** Rules
**نام کاربری گیت‌هاب:** GeekNeuron

## ویژگی‌ها

- نمایش قوانین اصلی در زبانه‌های (Tab) مجزا.
- قابلیت جستجو در بین مواد قانونی.
- دارای دو تم روشن و تاریک با قابلیت سوئیچ.
- نمایش سلسله مراتبی مواد قانونی (جلد -> بخش -> ماده).
- قابلیت برگزاری آزمون تصادفی از مواد قانونی.
- طراحی کاملاً فارسی و راست‌چین (RTL).

## نحوه راه‌اندازی روی GitHub Pages

۱.  یک ریپازیتوری (repository) جدید در اکانت گیت‌هاب خود با نام `Rules` (یا هر نام دلخواه دیگر) بسازید.
۲.  تمام فایل‌های این پروژه (`index.html`, `style.css`, `script.js`, `data.js`) را در این ریپازیتوری آپلود کنید.
۳.  به بخش `Settings` ریپازیتوری خود بروید.
۴.  در منوی سمت چپ، روی `Pages` کلیک کنید.
۵.  در بخش `Branch`، شاخه اصلی خود (معمولاً `main` یا `master`) را انتخاب کرده و روی دکمه `Save` کلیک کنید.
۶.  کمی صبر کنید. گیت‌هاب آدرس صفحه شما را (مثلاً `https://GeekNeuron.github.io/Rules`) نمایش خواهد داد و پروژه شما روی آن آدرس قابل مشاهده خواهد بود.

## فونت
فونت **وزیرمتن (Vazirmatn)** به‌صورت محلی در `assets/fonts/Vazirmatn.woff2` همراه پروژه است و آفلاین کار می‌کند (در `sw.js` کش می‌شود). مجوز آن SIL Open Font License 1.1 است و متن کامل مجوز در `assets/fonts/OFL.txt` قرار دارد.

## قابلیت‌های مطالعه (نسخه‌ی جدید)
- **آزمون هوشمند:** سه حالت «عادی / هوشمند / مرور اشتباه‌ها». در حالت هوشمند سؤال‌های اشتباه و ندیده بیشتر می‌آیند؛ با دو پاسخ درست پشت‌سرهم یک سؤال از فهرست اشتباه‌ها خارج می‌شود. گزینه‌ی «همه‌ی قوانین» و تعداد سؤال (۱۰/۲۰/۳۰) از تنظیمات.
- **آمار پیشرفت:** پاسخ‌ها، درصد درست، روزهای پیاپی، نمودار ۷ روز اخیر و ضعیف‌ترین قوانین (فقط در `localStorage` همین مرورگر؛ کلید `ilh-stats-v1`).
- **مرور شبانه:** صفحه‌ی تیره و گرم با متن درشت، از نشان‌شده‌ها یا ۱۵ ماده‌ی تصادفی؛ قفل خاموشی صفحه (Wake Lock) و خاموشی خودکار.
- **PWA:** قابل نصب (Android/Desktop با دکمه‌ی نصب در تنظیمات، iOS با «افزودن به صفحه‌ی اصلی»)، میان‌برهای آیکون و دانلود همه‌ی قوانین برای استفاده‌ی آفلاین.

### نکته برای توسعه‌دهنده
پس از افزودن یا تغییر هر قانون: `python3 tools/build_precache.py` را اجرا کنید و عدد `CACHE_NAME` را در `sw.js` بالا ببرید.
